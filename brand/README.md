# Salonat logo

The mark is the Arabic letter ص, the first letter of صالونات, on a rounded tile. Every letter in these
files is an outline, so they look the same everywhere, with no font installed.

| File | What it is | Use it |
|---|---|---|
| `salonat-mark.svg` | The mark: a white ص on a rose tile | On light backgrounds, and as an app icon or avatar |
| `salonat-mark-glow.svg` | A plum ص on a light rose tile | On dark backgrounds |
| `salonat-mark-1024.png` | The mark at 1024 px | Where SVG isn't accepted, such as social media profiles |
| `salonat-letter.svg` | The ص alone, in rose | For one colour: stamps, embroidery, watermarks |
| `salonat-lockup.svg` | The mark, "salonat" and "صالونات" on one line | For the platform, on light backgrounds |
| `salonat-lockup-on-dark.svg` | The same, for dark backgrounds | |
| `salonat-pro-lockup.svg` | The mark, with "salonat pro" over "صالونات برو" | For Salonat Pro, the app salons use, on light backgrounds |
| `salonat-pro-lockup-on-dark.svg` | The same, for dark backgrounds | |

The admin panel's browser tab and home-screen icons are in `admin-panel/src/app/`. At 32 px and
below, use its `favicon.ico`: the letter there is drawn bigger so it stays readable.

## Colours

| Name | Hex | In the admin panel |
|---|---|---|
| Rose | `#9C5A65` | `primary-600` |
| Plum | `#2C191D` | `primary-950` |
| Glow | `#E2B3A9` | `primary-300` |
| White | `#FFFFFF` | |

## Type

- The ص and the Arabic words: [Reem Kufi](https://github.com/aliftype/reem-kufi), Bold for the mark
  and SemiBold for the words.
- "salonat": [Outfit](https://github.com/Outfitio/Outfit-Fonts) SemiBold, with "pro" in Regular.
  Outfit is also the admin panel's font.

Both are under the SIL Open Font License. "Pro" is برو in Arabic, which has no "p".

## Using it

- Keep clear space around the mark of at least a quarter of its width.
- Use the colour pairs above; don't recolour, stretch, rotate or outline the mark.
