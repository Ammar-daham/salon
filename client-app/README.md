# client-app

Salonat, the app clients use to find a salon, see its free times and book. It will be a Flutter app for
iOS and Android, talking to [salon-backend](../salon-backend) like the [admin panel](../admin-panel) does.

**The app isn't built yet.** This folder holds what comes before the code:

| Folder | What's in it |
|---|---|
| [design](design) | Every screen of the app, as the sources of its design canvas |
| [docs/plan.md](docs/plan.md) | The plan to build it: phases, small tasks and a branch name for each |

The Flutter project will be created here, next to these folders, by the first task in the plan.
